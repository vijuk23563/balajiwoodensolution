Set Up Firebase — Go Online

Follow these 5 steps to make bookings save online and appear on any device

1
Create Project
2
Register App
3
Copy Config
4
Enable Firestore
5
Paste & Save
1

Create a Firebase Project

Open console.firebase.google.com in your browser. Sign in with your Google account.

Click "Add project" → Project name: balaji-wooden-solutions → Disable Google Analytics → Click "Create project".

Wait ~10 seconds for it to set up, then click "Continue".

2

Register Your Web App

On the project home page, click the </> (Web) icon.

App nickname: balaji-web → Click "Register app".

You'll see a code block with firebaseConfig — keep this page open.

3

Copy Your Config Values

You'll see something like this on the Firebase page:

// Your Firebase config will look like this: apiKey: "AIzaSyD-xxxxxxxxxxxxxxxxxxxxxxxxxxx", authDomain: "balaji-wooden-solutions.firebaseapp.com", projectId: "balaji-wooden-solutions", storageBucket: "balaji-wooden-solutions.appspot.com", messagingSenderId: "123456789012", appId: "1:123456789012:web:abcdefabcdef"

Copy these values — you'll paste them in Step 5.

4

Enable Firestore Database

In the Firebase console left sidebar → click Build → Firestore Database.

Click "Create database" → Select "Start in test mode" → Click "Next" → Choose any region → Click "Done".

⚠️

Test mode lets anyone read/write for 30 days — perfect for getting started. Later you can set up security rules when you're ready.

5

Paste Config into Your Website

Open the file js/firebase-config.js in VS Code / Kiro.

Replace the firebaseConfig block at the top of the file with your values:

const firebaseConfig = { apiKey: "PASTE_YOUR_apiKey_HERE", authDomain: "PASTE_YOUR_authDomain_HERE", projectId: "PASTE_YOUR_projectId_HERE", storageBucket: "PASTE_YOUR_storageBucket_HERE", messagingSenderId: "PASTE_YOUR_messagingSenderId_HERE", appId: "PASTE_YOUR_appId_HERE" };

Save the file. That's it! 🎉

✅ After Setup — What Happens

Every booking from any customer on any device goes directly to your Firebase database.
Open admin.html on your phone, laptop, or shop computer — same live data everywhere.

❓ Frequently Asked Questions

Is Firebase free?

Yes! Firebase's free tier (Spark plan) allows 50,000 document reads and 20,000 writes per day — more than enough for a booking website.

What if I haven't set up Firebase yet?

The website still works! Bookings save locally (in the browser). Once you set up Firebase, all new bookings go online automatically.

Can I access bookings from my phone?

Yes! After Firebase setup, deploy your site (Netlify Drop), then open admin.html on any device and all bookings appear in real-time.

How do I get notified of new bookings?

Currently via WhatsApp (customers send booking via WhatsApp button). For email notifications, you can add Firebase Cloud Functions later — ask Kiro to set that up.
